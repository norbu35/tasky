A: Mobile-width centered (Figma-faithful)

Keep the exact Figma layout in a ~480px centered column. Feels like a mobile app in the browser. Minimal web adaptation needed — same components, same spacing.

Pros

  • Pixel-perfect Figma match
  • Fastest to ship
  • Consistent cross-platform feel

Cons

  • Wastes screen real estate
  • Feels like a phone app on desktop
  • No advantage of wider viewport

B: Desktop-adapted (Recommended)

Same Figma design language (colors, typography, components) but adapted for wider viewports: horizontal nav, 2-column layouts, side-by-side content. Responsive down to mobile.

Pros

  • Uses screen real estate well
  • Feels native to desktop browsers
  • Same tokens, fonts, components as mobile
  • Proper responsive behavior

Cons

  • More layout work than option A
  • Layouts diverge from Figma (which is mobile-only)
