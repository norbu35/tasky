## HIGH (Open)

### HIGH-5: QPay Payment Integration Is a Stub (CARRIED)

`QPayPaymentProvider.createIntent()` returns synthetic URLs. If `escrow_enabled` toggle activates, customers see non-existent payment pages.

**Fix:** Complete QPay API integration before enabling escrow in production.

### HIGH-NEW: Frontend WebSocket Clients Connect Without Auth (NEW)

**Severity:** HIGH (broken feature — not a security vulnerability)

Web (`apps/web/src/pages/MessagingNotificationsPage.tsx:82-93`) and mobile (`apps/mobile/src/features/chat/components/ChatDetailScreen.tsx:59-72`) STOMP clients do not pass `connectHeaders` with the JWT. The backend `ChannelInterceptorConfig:58-61` correctly rejects STOMP CONNECT frames without `Authorization` header by throwing `IllegalArgumentException("Unauthorized")`, which closes the connection. **Result: real-time chat is completely non-functional.** Messages send via REST but live updates never arrive.

**Impact:** Core feature broken in all environments. `onStompError` only logs to console — no user-facing feedback.

**Fix:** Add `connectHeaders` to both STOMP clients:

```typescript
const client = new Client({
  webSocketFactory: () => new SockJS(socketUrl),
  connectHeaders: { Authorization: `Bearer ${session.accessToken}` },
  onConnect: () => { client.subscribe(...) },
});
```

**Note:** Backend auth enforcement is correct. This is a frontend bug, not a security hole.

## MEDIUM (Open)

### MED-NEW: BookingScheduleService JSON Metadata Still Uses Manual Concatenation (NEW)

`BookingScheduleService.java:66-67` constructs audit JSON with user-provided `reason` using only `reason.replace("\"", "\\\"")` — same vulnerability class as MED-7 (now fixed in ModerationService). Backslashes are not escaped. Input `test\` produces malformed JSON that PostgreSQL `CAST(... AS jsonb)` rejects → 500 error (DoS).

**File:** `services/api/src/main/java/mn/tasky/booking/application/BookingScheduleService.java:66-67`

**Fix:** Replace with `objectMapper.writeValueAsString(Map.of("proposed_at", proposedScheduledAt.toString(), "reason", reason != null ? reason : ""))` — same pattern as ModerationService fix.

### MED-4: No Encryption in Transit Between Containers (CARRIED)

postgres-exporter uses explicit `sslmode=disable`. App→MinIO is plain HTTP. Low risk on single-host.

**File:** `docker-compose.production.yml:151`

**Fix:** Add `sslmode=require` for multi-host deployments.

### MED-5: Backup Cron Writes Unencrypted pg_dump (CARRIED)

`backup-cron` writes uncompressed database dumps containing PII.

**File:** `docker-compose.production.yml:174-203`

**Fix:** Pipe through `gpg --symmetric --cipher-algo AES256` or use filesystem-level encryption.

### MED-8: Scheduled Jobs Lack Audit Actor Context (CARRIED)

Schedulers run via ShedLock without authenticated principal. Audit events may have null actor.

**Fix:** Define `SYSTEM_ACTOR_ID` constant for all scheduler-triggered audit entries.

### MED-9: Data Retention Only Covers Verification Images (CARRIED)

`DataRetentionService` handles banned-user verification deletion at 90 days. No retention for messages, task history, or financial records.

**Fix:** Define retention policy per data category. Messages (2 yr), task history (post-dispute), financial records (5-7 yr legal mandate).

### MED-10: Facebook Auth Status Exposed Without Authentication (CARRIED)

`GET /api/v1/auth/facebook/status` exposes circuit breaker state without auth.

**Fix:** Return only `available: boolean` from public response, or move behind auth.

### MED-INFO-1: No Tests for WebSocket Security Interceptor (NEW)

Zero tests exist for `ChannelInterceptorConfig`. No test verifying that STOMP CONNECT without Bearer is rejected, that SUBSCRIBE to unauthorized conversation is denied, or that rate limiting works.

**Fix:** Add integration tests for STOMP auth rejection, subscription authorization, and rate limiting.

## LOW (Open)

### LOW-1: Scripts Dockerfile Runs as Root (CARRIED)

`services/api/scripts/Dockerfile` uses `python:3.12-slim` without `USER` directive.

### LOW-2: Category Admin Mutations Missing Audit Trail (CARRIED)

`POST/PUT /admin/categories` don't capture `@AuthenticationPrincipal` for audit.

### LOW-3: Outbox Bulk Replay Without Rate Limiting (CARRIED)

`POST /admin/outbox/events/replay-all` loads up to 10,000 events synchronously.

### LOW-4: ServiceAreaController Untyped Request Body (CARRIED)

`PUT /taskers/me/service-areas` accepts `Map<String, List<String>>` without `@Valid` or size limits.

### LOW-5: Dev Auth Phone Numbers Hardcoded in Frontend (CARRIED)

Dev login phones in `AuthPage.tsx`. Backend is env-gated.

### LOW-6: Deep Link Scheme Has No Input Validation (CARRIED)

Mobile `tasky://` scheme without URL validation.

### LOW-INFO-1: WebSocket and CORS Allowed Origins Are Separate Configs (NEW)

`WebSocketConfig` uses `${tasky.websocket.allowed-origins}` while `SecurityConfig` uses `${tasky.cors.allowed-origins}`. If these drift in production, CORS may block REST while WebSocket remains open (or vice versa).

**Fix:** Cross-check or unify both configs.

### LOW-INFO-2: Frontend Swallows WebSocket Errors Silently (NEW)

Both web and mobile STOMP `onStompError` handlers only `console.error`. No UI indicator that real-time chat is broken. Users assume messages are delayed.

**Fix:** Show a "connection lost" banner when STOMP errors occur.

### LOW-INFO-3: Pattern Smell — 3 Services Still Build JSON via String Concatenation (NEW)

`DataRetentionService:102`, `NoShowService:172-173`, and `CategorySchemaVersionService:72` use string concatenation for JSON with UUID-only values. Low risk (no user input) but inconsistent with ObjectMapper pattern used elsewhere.

**Fix:** Replace with `objectMapper.writeValueAsString()` for consistency.
