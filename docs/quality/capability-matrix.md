# Capability Matrix

This document is the Tranche 2 capability audit ledger and working truth artifact. It classifies each product area using evidence from `docs/LAUNCH_ROADMAP.md`, `docs/API.yaml`, `docs/ARCHITECTURE.md`, and the current runtime/client code, and it records open canonical-doc discrepancies that require later-tranche rewrite work.

## Classification Legend

- `launch-live`: end-to-end launch baseline is live and used in the current rollout
- `implemented-gated`: implementation exists, but runtime access is feature-gated
- `partial`: meaningful pieces exist, but the capability is not end-to-end or has stubbed surfaces
- `contract-only`: API/spec or UI shell exists, but no runtime implementation was found
- `deferred`: explicitly marked deferred in roadmap/API and not yet implemented
- `archive`: retired or superseded capability outside the active product surface

No current scope row is assigned `archive`; that label is reserved for retired surfaces that should stay outside the active launch baseline.

When a row records an architecture-to-code discrepancy, that is an open finding for later-tranche canonical rewrite and code confirmation. It is not a settled override of `docs/ARCHITECTURE.md`.

## Evidence Summary

- Launch baseline and intentional deferrals are defined in `docs/LAUNCH_ROADMAP.md`.
- Phase-gated and deferred API behavior is documented in `docs/API.yaml`.
- Runtime gating for escrow/wallet/payouts is implemented in `services/api/src/main/java/mn/tasky/payment`, `services/api/src/main/java/mn/tasky/wallet`, and `services/api/src/main/java/mn/tasky/admin`.
- `lead_fee_enabled`, `subscription_enabled`, and `ai_scope_summary_enabled` are seeded latent capabilities with no confirmed runtime consumers in this sweep.
- `promoted_listings_enabled` and `b2b_enabled` are documented in `docs/ARCHITECTURE.md` as runtime-gated, but this code sweep found no matching backend or migration evidence; treat them as architecture-to-code discrepancies pending canonical rewrite and code confirmation.
- Ratified Phase 1 launch baseline: `docs/quality/launch-baseline-2026-04.md`.
- Canonical PRD appendix for deferred and dormant product surfaces: `docs/PRD.md` section "Latent Capabilities Appendix".
