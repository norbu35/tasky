# Document Taxonomy

Last updated: 2026-04-09

## Classification

| Document Surface | Status | Rationale | Location |
|---|---|---|---|
| `docs/plans/` | Live | Active tranche execution plans for maintenance and extension work | `docs/plans/` |
| `docs/superpowers/plans/` | Archived | Superseded greenfield planning artifacts; no longer active operational plan source | `archive/greenfield-docs/docs/superpowers/plans/` |
| `docs/superpowers/specs/` | Archived | Superseded design specs tied to archived superpowers plans | `archive/greenfield-docs/docs/superpowers/specs/` |

## Operating Rules

- New active plans must be created in `docs/plans/`.
- New active design and maintenance docs must stay under live `docs/` surfaces.
- Archived docs are historical-reference-only and should not be used as implementation authority.
