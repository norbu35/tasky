# ADR Directory

This directory stores Architecture Decision Records (ADRs) required by `AGENTS.md`.

## Naming
Use incremental numeric prefixes:
- `0001-title.md`
- `0002-title.md`

## Required Sections
1. Status (`proposed`, `accepted`, `superseded`, `deprecated`)
2. Date (ISO format)
3. Context
4. Decision
5. Consequences
6. Alternatives considered
