# B2B Pivot Strategy: The "High-Tech / Multi-Option" Model

## Vision
To evolve Tasky from a consumer-focused "marketplace" to a comprehensive **"Operations System for the Built Environment."** This positions Tasky not just as a place to find a worker when there's a problem, but as the automated system that prevents the problem from happening.

## 1. The "Omni-Channel" Automation Engine (Task Generation)
Instead of forcing manual entry, the B2B product becomes a central hub that ingests signals to automatically generate tasks.

*   **Tier 1: Webhook & API (The Developer Route):** Expose a public `/v1/b2b/tasks/create` endpoint. Larger property managers can integrate directly to trigger tasks from internal systems.
*   **Tier 2: Direct PMS Integrations (The SaaS Route):** Native OAuth integrations with major tools (Guesty, Hostaway, Airbnb, Booking.com). A guest booking automatically schedules a "Turnover Clean" for the checkout date.
*   **Tier 3: The iCal Scraper (The Universal Fallback):** For smaller hosts or obscure platforms, an iCal link sync. Tasky scrapes it daily and generates draft tasks for any new calendar events.
*   **Tier 4: IoT / Hardware Triggers (The Edge Route):** Allow tasks to be generated by physical events (e.g., A smart lock detects a checkout code being used -> Triggers a cleaning task; A water sensor detects a leak -> Triggers an emergency plumbing task). This justifies higher-tier subscriptions.

## 2. The Algorithmic "Auto-Pilot" Dispatch
Once a task is created, B2B customers use an automated rule engine rather than manual assignment.

*   **The "Waterfall" Dispatch Rule Engine:** B2B customers configure rules for assignment:
    1.  *Step 1 (T-minus 48h):* Ping my "Primary Roster" (favorite Taskers).
    2.  *Step 2 (T-minus 24h):* If no acceptance, ping my "Secondary Roster".
    3.  *Step 3 (T-minus 12h):* If unassigned, blast to the "Open Market" (all Pro Taskers).
    4.  *Step 4 (T-minus 4h):* **Surge Pricing Activates**. Platform automatically adds a premium (e.g., +50%, billed to the B2B client's card) to guarantee fulfillment.

## 3. The Quality Assurance (QA) Layer
Because B2B users are not physically present to inspect the work, the app provides rigorous validation.

*   **Geofenced Check-in/Check-out:** Taskers can only start the timer/checklist when their GPS verifies they are within 50 meters of the property.
*   **Mandatory Photo Checklists:** B2B customers define visual checklists. The Tasker cannot mark the job as complete until these specific photos are captured in real-time (gallery uploads blocked to prevent reuse).
*   **Issue Reporting Flow:** If a Tasker notices damage during a routine clean, they tap "Report Damage," take a photo, and the system automatically generates a new "Handyman Task" draft for the B2B host to approve.

## 4. Impact on Current Roadmap (Proposed PRD Changes)
If executed, this necessitates a fundamental restructuring of the PRD roadmap:

1.  **Delay C2C Monetization:** Keep C2C free (Phase 0-1) longer. Use it as a loss-leader to recruit and train the best Taskers.
2.  **Accelerate B2B SaaS:** Move `REQ-PAY-39` (B2B Billing) and `REQ-PAY-41` (PMS Integrations) from Phase 3/4 up to **Phase 2**.
3.  **The "Pro" Subsidy:** Shift "Tasky Pro" (`REQ-PAY-30`) from a paid subscription to an *earned status*. Pro Taskers receive exclusive access to high-paying, reliable B2B jobs. The B2B SaaS fees fund the platform, while Taskers get improved income stability without upfront fees.
