# Legacy Task System (Archived)

This folder contains the retired greenfield task queue:

- `tasks/` (legacy task markdown files)
- `task.sh` (legacy task queue script)

## Why archived

The repository has shifted from generated greenfield execution to maintenance-mode planning and tranche execution via `docs/plans/`. The old queue is preserved for traceability but is no longer active workflow machinery.

## Do not use for active work

- Do not run `archive/legacy-task-system/task.sh` to manage current work.
- Do not add new task files under `archive/legacy-task-system/tasks/`.
