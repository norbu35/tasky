# Future Design Drafts

This archive preserves deferred design drafts that are outside the active Phase 1 design path.

`docs/design/**` remains the canonical active design surface. Files in this archive are historical reference only and
must not be used as launch UX, copy, contract, or implementation authority.

Move a draft back into `docs/design/**` only when the governing product and rollout documents activate that phase.
That workflow must also update the affected design contracts, launch-facing copy, verification, monitoring, and rollback
guidance so the runtime product does not outrun the active Phase 1 baseline.
